## 1. What is a String?

A **string** is a sequence of characters.

```text
"Hello"

Index:
0 1 2 3 4
H e l l o
```

- Characters are accessed using their index.
- Indexing starts from **0**.
- Accessing any character (`str[i]`) takes **O(1)** time.

## 2. String Immutability

JavaScript strings are **immutable** — they cannot be modified after creation.

```js
let str = "cat";

str[0] = "b";

console.log(str); // "cat"
```

To "modify" a string, JavaScript creates a **new string**:

```js
let str = "cat";

str = "bat";
```

The original `"cat"` still exists until it is garbage collected.

### Interview point

Methods like `toLowerCase()`, `toUpperCase()`, `replace()`, `slice()`, and `trim()` **do not modify the original string** — they return a **new string**.

## 3. String Complexity

| Operation                   | Complexity |
| ---------------------------- | ---------- |
| Access character (`str[i]`)  | O(1)       |
| Traverse entire string       | O(n)       |
| Create new string            | O(n)       |

## 4. Traversal Pattern

### Use when

The problem requires examining **every character** of the string.

Examples: count vowels, count digits, count uppercase letters, find the maximum character, sum of digits inside a string.

### Template

```text
Initialize required variables
Loop through string
  Process current character
  Update the required state
Return the final answer
```

### Complexity

- Time: **O(n)**
- Space: **O(1)** (if only variables are used)

## 5. Lower Bound Principle

Before solving any problem, ask:

> Can I solve this without looking at every character?

If the answer is **no**, the best possible time complexity is **O(n)** — this is called the **lower bound**.

Example: to count vowels, every character must be inspected at least once.

## 6. State

**State** is the information maintained while processing the input.

| Problem      | State     |
| ------------ | --------- |
| Count vowels | count     |
| Find maximum | max       |
| Sum digits   | sum       |
| Count words  | wordCount |

The state changes as the algorithm progresses.

## 7. Loop Invariant

A **loop invariant** is a condition that remains true after every iteration of the loop.

Example, while counting vowels:

> After processing the first `i` characters, the variable `count` stores the number of vowels found in those `i` characters.

Loop invariants help prove that an algorithm is correct.

## 8. Two Pointer Pattern

### Use when

Processing data from **both ends simultaneously** — reverse string, valid palindrome, merge sorted arrays, container with most water.

### Template

```text
left = first index
right = last index

while (left < right)
  Perform required operation
  left++
  right--
```

### Complexity

- Time: **O(n)**
- Space: **O(1)**

## 9. Big-O Rule

Big-O ignores **constant factors**.

```text
O(n)
O(2n)
O(n/2)
O(10n)
```

All simplify to:

```text
O(n)
```

Although `O(n/2)` performs fewer operations, both algorithms still grow **linearly** with the input size.

## 10. Pattern Recognition (Most Important)

Before writing code, ask:

```text
Need every character?      -> Traversal
Need both ends?            -> Two Pointers
Need fast lookup?          -> HashSet / HashMap
Need frequency count?      -> HashMap
Need continuous substring? -> Sliding Window
```

## 11. Problem-Solving Checklist

1. What is the **input**?
2. What is the expected **output**?
3. Which **pattern** fits this problem?
4. What **state** should be maintained?
5. What is the **stopping condition**?
6. What is the best possible **time complexity**?
7. Are there any **edge cases**?

## Key Learning

A DSA problem should be solved in this order:

```text
Understand the problem
        ↓
Identify the pattern
        ↓
Design the algorithm
        ↓
Analyse complexity
        ↓
Write the code
```
