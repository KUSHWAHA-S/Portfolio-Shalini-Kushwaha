## `charCodeAt(index)`

`index` is the position to inspect inside the string. Strings are zero-indexed, so the first character is always at `0`.

| Char | H | e | l | l | o |
| --- | --- | --- | --- | --- | --- |
| Index | 0 | 1 | 2 | 3 | 4 |

```js
"JavaScript".charCodeAt(0) // 74  -> 'J'
"JavaScript".charCodeAt(4) // 83  -> 'S'
"JavaScript".charCodeAt(9) // 116 -> 't'
```

An out-of-range index returns `NaN` — no character exists there.

## Why `Array.from(str, cb)` always uses index `0`

```js
Array.from("Hi", char => char.charCodeAt(0))
```

`Array.from` first **splits the string into single-character strings**, then runs the callback on each one — `cb` never sees `"Hi"`, it sees `"H"` then `"i"`, one call at a time. Each chunk is its own brand-new one-letter string, so the character you want is always at index `0`, regardless of where it sat in the original string.

```text
"Hi" -> ["H", "i"] -> charCodeAt(0) on each -> [72, 105]
```
