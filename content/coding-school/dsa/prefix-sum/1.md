## Mental Trigger

> Count contiguous subarrays with a specific sum — especially when negative numbers are involved, since sliding window can't be trusted when sums aren't monotonic.

## LeetCode 560 — Subarray Sum Equals K

`currentSum` is the running sum from the start of the array to the current index. For a subarray between two prefixes:

```text
subarraySum = currentPrefix - previousPrefix
```

We want `currentPrefix - previousPrefix = k`, so the prefix we're looking for is:

```text
needed = currentPrefix - k
```

Store `prefixSum → frequency` in a map.

```js
function subarraySum(nums, k) {
  const freq = new Map([[0, 1]]) // prefix sum 0, before the array starts
  let currentSum = 0
  let count = 0

  for (const num of nums) {
    currentSum += num
    const needed = currentSum - k
    count += freq.get(needed) || 0
    freq.set(currentSum, (freq.get(currentSum) || 0) + 1)
  }

  return count
}
```

### Why seed with `0 → 1`?

It represents the prefix sum *before* the array starts, so a subarray beginning at index `0` can still be counted.

### Check before you store

Same principle as Two Sum: look up `needed` **before** adding the current prefix sum to the map, or a subarray could match against itself.

## LeetCode 974 — Subarray Sums Divisible by K

Same shape, different question — track `currentSum % k` instead of `currentSum - k`.

**Key insight:** if two prefix sums share the same remainder, `prefix2 - prefix1` is divisible by `k`. So store `remainder → frequency` instead of `prefixSum → frequency`.

```js
function subarraysDivByK(nums, k) {
  const freq = new Map([[0, 1]])
  let currentSum = 0
  let count = 0

  for (const num of nums) {
    currentSum += num
    const remainder = ((currentSum % k) + k) % k // normalize negative remainders
    count += freq.get(remainder) || 0
    freq.set(remainder, (freq.get(remainder) || 0) + 1)
  }

  return count
}
```

### Why normalize the remainder?

JavaScript's `%` can return negative values (`-2 % 5 === -2`), but remainders should stay in `0..k-1`. `((x % k) + k) % k` fixes that.
