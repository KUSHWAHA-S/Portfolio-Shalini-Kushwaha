## Mental Trigger

> Find the smallest contiguous window satisfying a frequency requirement.

## LeetCode 76 — Minimum Window Substring

Maintain:

```text
targetMap                        — required frequency
windowMap                        — frequency currently in window
matches                          — how many required chars are currently satisfied
left, right                      — window bounds
minLength, startIndex, endIndex  — best answer found so far
```

## The Expand/Shrink Pattern

```text
expand right → become valid → shrink from left → record smallest valid window → continue expanding
```

Shrink **only while the window stays valid** — the moment removing a character would break validity, stop shrinking and go back to expanding `right`.

## Critical Insight

The answer isn't necessarily the first valid window found. Keep `minLength`/`startIndex`/`endIndex` and update them whenever a smaller valid window appears.

## Mental Model

```text
right → make the window valid
left  → make the valid window as small as possible
```

Same fixed-window machinery as Day 1 (`targetMap` / `windowMap` / `matches`) — just with the window size no longer fixed. It grows to find validity, then shrinks to minimize.
